# FLOW TAREFAS

Aplicação para organização e acompanhamento de tarefas em fluxo (estilo Kanban).

## Sobre o projeto

O **FLOW TAREFAS** é um sistema para gerenciar tarefas do início ao fim, movendo cada
atividade entre etapas do fluxo de trabalho (por exemplo: _A fazer_ → _Fazendo_ →
_Concluído_). O objetivo é ter uma visão clara do andamento das tarefas em um só lugar.

## Funcionalidades planejadas

- [ ] Criar, editar e excluir tarefas
- [ ] Organizar tarefas por colunas/etapas do fluxo
- [ ] Definir prioridade e prazo
- [ ] Marcar tarefas como concluídas
- [ ] Filtrar e buscar tarefas
- [ ] Persistência dos dados
